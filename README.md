# 慢病健康管理专家团 · DSH 插件

[English](README.en.md) | 中文

面向**患者本人**的慢病照护面板。它先看症状、再看数字：血压、血糖、体重、腰围、尿酸、eGFR 一条条录进去，趋势图把用药事件画成竖线，患者自己调的药单独用红色虚线标出来。

最重要的一句话写在面板最显眼的位置，字号压不小：

> **必须在医师指导下调整治疗方案。**
> 任何加量、减量、停药、换药或注射剂量调整，都要先联系经治医师。

## 装了之后有什么

| 装了什么 | 内容 |
|---|---|
| **左侧边栏面板** `慢病管理` | 三栏照护面板：健康档案 / 用药时间轴 / 报告 |
| **技能** `chronic-care-team` | 照护总监「康有方」口径：六条不可违背的规则、妊娠闸门、A/B/C 数据可信度、四级就医建议 |
| 一键 | 「复制健康简报」把事实包放进剪贴板，粘进对话即可 |

## 面板里有什么

- **健康档案**：每条指标带 数值 / 单位 / 测量日期 / 测量条件 / **A・B・C 可信度**。C 级不参与达标结论。
- **用药时间轴**：药名、剂量、起止、**谁决定的**（医嘱 / 自己调的）。自己调的那几条会在报告区单独高亮——只记录时间和内容，提示尽快联系医师，**不评判、不建议新剂量**。
- **趋势图**：完全自包含的内联 SVG，不联网、不引 CDN。每个指标一张子图，目标范围用浅色带标出，用药事件画竖线，自调药是红色虚线。
- **急诊红线**：突发剧烈头痛 / 一侧无力 / 胸痛胸闷超 10 分钟 / 喘不上气或粉红泡沫痰 / 意识不清的低血糖 / 恶心呕吐伴呼吸深快嗜睡 / 尿量骤减伴水肿——命中任一项，横幅立刻变红置顶，只留「现在做什么」和「立即就医 / 拨 120」，其余内容全部收起。
- **妊娠闸门**：女性先问「是否怀孕或近半年打算怀孕」。答含糊或没答，一律按**可能妊娠**处理：暂停用药建议，列出医师核对清单（ACEI/ARB、他汀、司美格鲁肽、SGLT2i、降尿酸药、抗凝药），提示转产科 + 开药专科共管。
- **三段结论 + 四级就医建议**：健康建议 / 饮食指导 / 就医建议三段，加 🟢居家 🟡门诊随访 🟠尽快专科 🔴立即急诊。
- **术语先说人话**：面板里内置小词表（"收缩压 = 量血压时上面那个数"）。

## 用起来是什么流程

1. 左侧边栏打开「慢病管理」，先填性别和年龄（妊娠闸门要用）。
2. 逐条录指标与用药；有不适就写在「症状」里。
3. 点 **复制健康简报** → 粘到对话里发送。
4. 对话按 `chronic-care-team` 的规则给出三段结论；把结论粘回面板留档。

## 安装

```sh
dsh plugin --profile web add "https://github.com/flying-ovaltine/chronic-care-workbench/releases/latest/download/dsh-chronic-care-team.tgz"
```

或在 **插件 → 插件市场** 搜「慢病」。

```sh
pnpm install && pnpm build && node --test test/smoke.mjs
```

## 隐私与边界

- 数据只存在**本机浏览器 localStorage**，不上传任何第三方；界面不回显真实姓名、住院号、身份证号。
- **不做诊断、不开处方**，只给分析与路径。
- 仅用于健康管理与宣教，不构成医疗建议；出现红线症状请立即就医。
